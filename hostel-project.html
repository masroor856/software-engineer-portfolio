PROJECT 01 · FULL-STACK

Hostel Management System

A full-stack web application designed to simplify hostel accommodation management, user registration, room management, payments, and administrative operations through a centralized system.

About the Project

The Hostel Management System was developed to provide a centralized platform for managing hostel-related activities.

The system is designed to support both hostel administrators and users. Administrators can manage products and hostel-related information, while users can register, authenticate, view available information, create plans, and track their activities.

The project demonstrates practical experience with backend development, database management, authentication, authorization, CRUD operations, and frontend integration.

Technologies Used

C# ASP.NET Core Entity Framework Core SQLite HTML5 CSS3 JavaScript

Key Features

User Authentication

Users can register and securely log into the application.

Role-Based Authorization

Different access levels are provided for administrators and regular users.

Database Management

Entity Framework Core is used to manage application data and database operations.

CRUD Operations

The system supports creating, reading, updating, and deleting application records.

Administrative Management

Administrators can manage system information through protected functionality.

Responsive Interface

The frontend is designed to provide a usable experience across different screen sizes.

Application Architecture

Frontend: HTML, CSS and JavaScript

Backend: C# and ASP.NET Core

Data Access: Entity Framework Core

Database: SQLite

Authentication: ASP.NET Core Identity

Authorization: Role-based access control

What I Practiced

This project helped me develop practical experience in designing and implementing a full-stack web application using C# and ASP.NET Core.

I practiced working with controllers, models, database contexts, Entity Framework Core, authentication, authorization, CRUD operations, and frontend-to-backend integration.
